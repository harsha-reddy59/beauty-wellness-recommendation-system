# Beauty & Wellness Recommendation System

## 📌 Overview
This project aims to reduce choice overload in skincare by building a personalized recommendation system using data science techniques.

## 🎯 Problem Statement
Customers struggle to choose suitable skincare products due to:
- Too many options
- Generic ratings
- Lack of personalization

## 💡 Solution
A hybrid recommendation system combining:
- Content-based filtering (product features)
- Collaborative filtering (user behavior)
- Review sentiment analysis
